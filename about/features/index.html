Features

NME supports many features, including the following:

Graphics

  • Support for bitmap graphics
  • Support for vector graphics
  • Support for direct-pixel manipulation
  • Support for batch triangle rendering
  • Support for batch tile rendering
  • *Direct access to OpenGL for custom rendering

Media

  • Support for audio playback
  • *Support for dynamic audio generation

Networking

  • Support for HTTP requests
  • Support for low-level socket networking
  • Support for application cache data

Text

  • Support for device text rendering
  • Support for embedded font rendering
  • Support for custom font rendering
  • Support for simple HTML rendering

Input

  • Support for keyboard input
  • Support for mouse input
  • Support for multitouch input
  • *Support for joystick input

Miscellaneous

  • Support for fullscreen applications
  • Support for windowed applications
  • Support for multiple screen densities
  • *Support for native platform extensions
  • *Support for multi-threading
* available for native targets

Library Support

NME can be used with many libraries, providing features such as:
  • Support for tween animation
  • Support for rigid-body physics
  • Support for spritesheet animation
  • Support for direct database access
  • Support for tile maps
  • Support for particle effects
  • Support for SWF assets
NME is also compatible with popular game frameworks like Flixel and HaxePunk.

Platform Support

Windows, Mac, Linux, iOS, Android, and JSPrime

Build Tools

NME integrates support to deploy for each platform, automating the compile, package and deployment steps, with a single, easy-to-use command-line tool.
The NME command-line tools can be integrated into an existing build process, or from a code editor with support for NME, such as FlashDevelop, IntellijIDEA or Sublime Text 2.
