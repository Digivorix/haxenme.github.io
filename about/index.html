What is NME

NME is the best way to build cross-platform 2D games or rich applications.

For over fifteen years, we have been building a way to bring your content to every major platform, without the compromise or trade-offs of most cross-platform solutions.

Using the innovative Haxe language compiler, NME deploys the same source code to multiple platforms without sacrificing reliability. As a result, NME provides fast hardware-accelerated performance for Windows, Mac, Linux, iOS, and Android while also supporting web builds through its JSPrime target

NME mirrors the traditional Flash API, so developers can leverage their existing experience to target new platforms, with better results. Developers with experience in ActionScript 3, Java or C++ can quickly learn to use NME without a long on-ramp.

NME balances the demands of a fast and easy-to-use workflow with the requirements of building a quality product, giving you stronger returns on your investment.
