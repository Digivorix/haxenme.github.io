FAQ

General

What is NME?
NME is a framework for building games and applications for mobile and desktop platforms.
What target platforms does NME support?
NME supports Windows, Mac, Linux, iOS, and Android. Web builds are also possible through the jsprime target.
What host platforms does NME support?
NME supports Windows, Mac and Linux development environments. Most targets are supported for each desktop, but iOS cannot be built from Windows or Linux due to a lack of vendor support.
What does it cost to use NME?
Nothing, NME is free of charge.
What programming language does NME use?
NME uses a language called Haxe. Haxe is a "multi-platform" programming language, designed to reliabily support multiple languages from the same source code.
